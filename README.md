# 佛光寺东大殿 · 木构之间

此副本已适配 GitHub Pages。发布说明见 [GITHUB-PAGES.md](GITHUB-PAGES.md)，已编译网页位于 `dist/`。

静态资源使用相对路径，可部署在 `/<仓库名>/` 下；浏览器无需访问 ChatGPT 或第三方 CDN 即可加载模型。通过 GitHub Actions 构建并发布，访问地址由仓库的 Pages 页面提供。

以 TypeScript、Three.js 与 Vite 实现的唐代木构交互展示。建筑、屋面、筒瓦、斗拱、材质、山体及植被全部在运行时由代码生成。没有外部三维模型、图片纹理、字体或 CDN 依赖。

## 启动

使用 Node.js 22.12 或以上版本。在本项目目录执行：

```bash
npm ci
npm run typecheck
npm run verify
npm run build
npm run dev
```

开发服务器端口为 4173，启动后打开终端给出的本地地址。生产输出位于 `dist/`；执行 `npm run preview` 可预览生产文件。不能直接双击 `index.html` 打开模块项目，需使用 HTTP 服务。

源码包包含已编译的 `dist/`，可上传至支持静态网页的服务。运行时不请求第三方模型或纹理；安装依赖时仍需 npm 软件源。

## 功能

- 七开间、四间进深的横向殿堂；内外柱网共 36 个柱位，柱身有轻微收分。
- 四片连续参数曲面构成单檐庑殿顶；低缓曲线、深出檐、轻微屋角起翘、正脊、四条垂脊与简化鸱尾。
- 灰色筒瓦、瓦垄、椽头、瓦当暗示；重复筒瓦使用 InstancedMesh，并带确定性随机色差。
- 柱头、补间、转角和内柱斗拱；斗、拱、昂、枋表现层层出挑关系。
- 梁、枋、檩、椽及简化屋架，石础、石台基、中央石阶、墙体、门扇和格栅。
- 山地、远山、院落、院墙、辅助建筑轮廓、古松柏与草地；针叶贴图用 Canvas 程序生成。
- OrbitControls：左键旋转、滚轮缩放、右键平移、触屏手势。
- 自动环绕；手动操作暂停，松手 4 秒后继续。
- 爆炸与重组：按层次错峰执行，约 4 秒；可中途反向，始终从保存的初始位置、旋转及缩放计算。
- 结构模式：让瓦面与墙体半透明，突出柱、梁、枋、斗拱、檩、椽，并附图例。
- 主要构件 Hover 名称、点击知识卡片和靠近观察。
- 37 秒自动演示：观殿 6 秒 → 透顶 6 秒 → 梁架 6 秒 → 铺作 6 秒 → 拆解 7 秒 → 合拢 6 秒。
- 院落步行漫游：拖动环顾、WASD / 方向键移动，触屏方向键；主要围护设有简化边界。
- 全屏、初始视角、移动端布局、WebGL 不可用和上下文中断提示。
- 浏览器支持时注册三项 WebMCP 能力：读视图状态、切换模式、打开构件卡片。

自动演示是网页实时动画，不含单独的视频文件、解说音轨或音乐。

## 性能与资源

当前场景包含约 68.5 万个三角形、98 个网格对象，以及约 3.42 万个实例或普通构件。数字是完整场景的几何统计，不能直接等同于每帧总 Draw Calls；阴影和后处理有额外渲染开销。

- 重复筒瓦、斗拱、柱、梁架、椽、草和树使用 InstancedMesh。
- 院墙合并静态 Geometry，树冠使用三向交叉针叶面片。
- DPR 上限为 2；太阳阴影贴图为 2048²。
- 宽屏且逻辑核心数量满足条件时启用 SSAO；持续高帧耗时下关闭 SSAO，并将 DPR 降至不超过 1.25。
- ACESFilmicToneMapping、SRGBColorSpace、PCFSoftShadowMap。
- 场景、材质、纹理、后处理、监听器与 ResizeObserver 在销毁时释放。

帧率尚未在实际桌面 GPU 或手机上测量，不承诺特定设备达到 60 FPS。

## 本次续作与验证

修正了右键平移、拖动回原点和取消触点误开知识卡片的问题；漫游退出、失焦及打开说明时会清理按键和拖动状态。自适应 DPR 同时更新渲染器与后处理缓冲区。结构化工具读取即时状态，并拒绝不符合对象约束的输入。

`npm run verify` 执行两组验证：几何 / 重组断言，以及 17 项页面交互逻辑检查。后者在 Happy DOM 中运行实际 UI、建筑几何、OrbitControls、相机、Raycaster、时间线和 EffectComposer 缓冲对象；不创建 WebGLRenderer，也不验证真实 GPU、CSS 排版、纹理像素或触屏设备。类型检查与生产构建已通过。当前验收浏览器禁用了 WebGL，浏览器最终视觉效果仍有待在可用设备中检查。完整证据与范围见 `docs/VALIDATION.md`。

## 建筑真实性

这是用于理解结构关系的程序化近似模型。保留建筑识别特征，尚未依据完整测绘图或扫描点云逐构件校核。特别是梁架与月梁、叉手、榫卯、转角铺作、各间尺寸、门窗、屋脊装饰、寺院高差及辅助建筑存在简化。柱网和尺寸参数用于视觉组织，不应作为文物修缮或工程设计依据。

没有复原佛像、壁画、平棊及内部宗教陈设。结构图例配色是识别辅助，并非历史彩绘。鸱尾采用形态示意，不将现存屋脊细节全部视为唐代原物。爆炸动画是展示路径，并非真实拆卸工序。

建筑背景参考 [UNESCO 五台山世界遗产说明](https://whc.unesco.org/en/list/1279/)。该说明强调东大殿及其山地环境的重要性；它不是本模型的逐构件测绘来源。开间、屋顶类型和主要形态要求以项目任务书为基础。
